description: rules agreed with the user for the hub/dating split (who appears in Swipe Cosmici, what non-dating users can do)

- Only profiles with dating on appear in Swipe Cosmici; non-dating users may browse cards view-only (no like, message, favorites, reactions) and get an "Attiva il tuo profilo dating" invite.
- Leaving dating hides the card but keeps existing matches and conversations.
- Turning dating on requires gender, "Cerco", bio and a photo; the "Cerco" filter stays a hard filter (user's choice).
- New sign-ups get a base profile with dating off and see a bivio once; existing profiles default to dating on.
- The hub reminder is dismissible and must not reappear on every login.
**Why:** confirmed by the user when planning the hub/dating split (Oct 2026).
**How to apply:** keep these rules when touching swipe, profile-edit, registration or admin user lists.
